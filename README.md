# Fit Tracker

Трекер тренировок. Приложение хранит все данные на телефоне, аккаунт не нужен.

## Как получить APK

1. Создайте репозиторий на github.com (кнопка New repository).
2. Загрузите в него все файлы из этой папки (Add file, Upload files). Папку `.github` с файлом `workflows/build-apk.yml` создайте вручную: Add file, Create new file, в имени введите `.github/workflows/build-apk.yml` и вставьте содержимое.
3. Откройте вкладку Actions. Сборка Build APK запустится сама после загрузки, она идёт 5-10 минут.
4. Когда появится зелёная галочка, откройте на главной странице репозитория раздел Releases справа и скачайте `app-debug.apk`.
5. Откройте файл на телефоне и разрешите установку из этого источника.

## Как обновить приложение

Замените файл `www/index.html` в репозитории. Сборка запустится заново, в Releases появится новый APK. Данные в приложении при обновлении сохраняются, если установить новую версию поверх старой.
